# Visual Assets and Design References

## Design reference

The interface references the University of Delaware's blue/gold palette and typography hierarchy:

- Brand style guide: https://www.udel.edu/content/dam/udelImages/ocm/style-guide/brand-style-guide.pdf
- Digital guidelines: https://www.udel.edu/home/ocm/digital/
- Official marks policy: https://www.udel.edu/home/ocm/brand/logos/

This independent class project does not reproduce the University's official logo, seal, mascot, proprietary font files, or official website header. Plain university-name text identifies the student-project context and is not an endorsement claim.

## Fonts

Unmodified Open Sans and Oswald variable fonts are bundled from the Google Fonts repository. Both use the SIL Open Font License 1.1. The complete copyright notices and licenses accompany the files:

- `fonts/OpenSans.ttf`: https://github.com/google/fonts/tree/main/ofl/opensans
- `fonts/OpenSans-OFL.txt`
- `fonts/Oswald.ttf`: https://github.com/google/fonts/tree/main/ofl/oswald
- `fonts/Oswald-OFL.txt`

The UD guide identifies Open Sans and Oswald as digital alternatives when official brand fonts are unavailable. No proprietary Greycliff or Vanguard font is bundled.
